# Adaptive NPCs using Reinforcement Learning

## Overview
This project explores adaptive NPC behavior using Reinforcement Learning in Unity.
The goal is to compare traditional scripted AI with learning-based agents.

## Features
- Multi-Agent System (Hunter vs Collectors)
- Reinforcement Learning using PPO (Unity ML-Agents)
- Dynamic environment with coin collection mechanics
- Multiple training iterations

## Technologies
- Unity
- ML-Agents
- Python / PyTorch
- TensorBoard

## Training Iterations
- Iteration1: initial setup
- Iteration2: improved reward system
- Iteration3: optimized agent behavior
